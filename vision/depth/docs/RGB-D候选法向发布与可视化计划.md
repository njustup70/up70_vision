# RGB-D 候选法向发布与可视化计划

> 2026-11-02；本计划面向现有实时侧面查看器。已实施内容与验证范围以深度 progress 为准。

## 目标和边界

在 YOLO + RGB-D 候选发布链路中，将同一选中可见平面的重心和法向一起交给下游 ROS 节点，并在 RViz 显示。复用当前节点，不拆分 YOLO 与深度处理；不增加顶面分类、跨帧跟踪、机械臂变换或动作。选面不证明箱体实例正确，也不代表吸附点。

## 对外接口

沿用 `/rgbd_side/candidates` 的 `vision_msgs/Detection3DArray`；QoS 可靠、易失、深度 1。每项 `results[0].pose.pose.position` 为可见内点重心，单位米；四元数旋转局部 +Z 至选中平面的单位法向，方向朝相机，绕法向转角是构造值。类别和分数来自 YOLO，`id` 留空，协方差和零尺寸 bbox 未估计。header 使用配对深度图的采集时间与光学 frame。字段与接收公式以 [接口契约](../../docs/interface.md#rgb-d-可见平面候选输出2026-11-02) 为准。

该四元数由单位占位变为携带方向，是接口语义变更；合入前按团队规范请搭档评审，并通知现有订阅方。发布端验证法向为三个有限数且模长大于 1e-9，归一化并使 `n·(-p) ≥ 0`；非法法向的整项候选不发布并计数。相机内部与算法毫米、ROS 输出米，不能仅更改 frame_id 假装转换到基座系。

## RViz 与失效

`/rgbd_side/markers` 保留黄色重心和文字，新增起点 `p`、终点 `p + 0.10n` 的青色箭头，箭头长度仅为显示比例。各候选的点、文字、箭头独立编号，具有有限生命周期。过期、断流、时间倒退、内参变化或处理失败时，沿用现有空数组及标记清除策略。订阅者还须自行检查结果时间和断流。

## 验证

- 合成测试：正反轴向、斜向、符号翻转、非法输入、多框关联、箭头起终点、过期与 epoch 重置；从四元数恢复 +Z 的分量误差小于 1e-6。
- bag 回放：订阅候选和标记，与同一图对重算的法向比较；确认空结果清除并观察 RViz。软件一致性不等于真机法向准确度。
- 真机：人工确认箱面，分别记录正视、约 45°、移动和出画，观察箭头与选面；至少 60 秒，记录频率、几何重置、过期、通信错误和滤波状态。场景未完成或结果不稳定须保留未验证状态。
- 不执行 `vision clean`；完整回归在隔离副本运行。空间、绝对位置和法向角度精度均需独立参考验证。
