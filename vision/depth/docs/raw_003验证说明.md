# raw_003 深度位姿验证与图表

## 输入与边界

`bags/raw_003` 包含 372 帧深度图和 CameraInfo，不含彩色图。`meta.yaml` 的 205mm 和 60° 来自进度记录中的直尺与手机水平仪读数，测量基准及不确定度未知。中心相机系绝对坐标没有独立真值；单帧抖动只表征重复性，不能用来签署 M2。

内参与每帧采集时间、坐标系均来自 bag。深度以历史配置 `enable_depth_scale=true` 作为毫米处理；保存 K/D/R/P 和畸变模型，图像校正关系仍需独立确认。纯光学系 XYZ：X 右、Y 下、Z 前；法向朝相机。旋转四元数只保证局部 Z 轴指向法向，绕法向的角度不是实测 yaw。

## 运行

镜像需要 `.[lab]`，其中包括 rosbags 和 matplotlib；修改依赖后应重新构建镜像。代码在容器 `/opt/vision`：

```bash
docker compose -f .devcontainer/docker-compose.yml build
docker compose -f .devcontainer/docker-compose.yml run --rm up70-vision \
  python -m lab.depth_report.analyze bags/raw_003 --out output/depth/raw_003
docker compose -f .devcontainer/docker-compose.yml run --rm up70-vision \
  python -m lab.depth_report.render output/depth/raw_003
```

打开 `output/depth/raw_003/report.html`：五类结果图与首、中、末帧图、机器可读的 `summary.json`、逐帧 `frames.csv` 和可复绘的 `visual_data.npz` 均在同一目录。图片文字为 ASCII，报告为中文。点云图限定 Z≤1200mm 以便观察近处物块，仅影响显示；紫色顶层依据记录的桌面平面参数重建，不是人工标注真值。

## 统计口径

使用前 60 帧深度时间中位数做原五项检查；使用完整 bag 的每帧检测计算逐帧位置中位数与标准差。固定参数与随机种子记入 JSON，逐帧候选数和分数记入 CSV。阈值为 score ≥0.5：零合格候选为 missing、多候选为 ambiguous，不计入位置统计但保留分母。相邻有效帧位移超过 30mm 标为疑似切换，只作诊断，不自动删帧。

图像单帧时间戳保留纳秒，算法内部毫米、ROS 输出米。静止情况要检查首、中、末图；独立位移验证需要固定相机、尺测网格、不同位置的 bag 与测量不确定度。
