# 人工框与对齐深度：离线诊断原型

本工具用于在现有同步 RGB-D bag 的选中图对上检查人工框和深度候选的对应关系；不是实时融合节点，不能用于控制机械臂。输入使用 `lab.rgbd_check analyze` 生成的报告，不修改原包或原报告。依赖项目的 `[lab]` 可选依赖和支持 GUI 的 OpenCV。

```bash
# 首次从 bag 生成报告；输出目录必须不存在
python -m lab.rgbd_check analyze bags/raw_036 --out output/rgbd/near_example
# 在校正后的彩色图中用鼠标拖框，回车确认；输出目录必须不存在
OPENBLAS_NUM_THREADS=1 python -m lab.manual_rgbd_fusion output/rgbd/near_example --out output/manual_fusion/near_example
# 自动复现时可提供该校正网格的框，坐标为半开 [x1, y1, x2, y2)
OPENBLAS_NUM_THREADS=1 python -m lab.manual_rgbd_fusion output/rgbd/near_example --out output/manual_fusion/near_bbox --bbox 338 65 488 360
```

窗口选择框时，显示的是利用本包彩色 K/D 映射到对齐深度零畸变 K 的图，而不是原始带畸变图。传 `--bbox` 时坐标同样必须在此校正网格；不能将原图上的框不加转换地使用。脚本核查对齐模式、采集完整性、时间配对、两路尺寸和 frame；只支持 plumb_bob 彩色与零畸变对齐深度。校正依据依赖驱动发布的参数，空间验收未通过时仍有物理误差风险。

程序在完整深度图上运行现有深度算法，再用框与合格簇的重叠关联目标。框内没有簇、存在多个簇、或簇多数在框外，都明确输出无候选或歧义。脚本以 50 个重叠像素、簇内 50% 比例作为调试启发式，并非验收门槛；它不能保证一个簇只包含一个箱子，也不能自动验证支撑平面、顶面或吸附点。深度 0 保留为无效值，未插值补洞。

输出 `rectified.png`、`cluster.png`（绿框、黄色深度簇）、`cluster_mask.png` 和 `result.json`，包含选中图对时间戳、CameraInfo frame、关联状态、有效深度比例、候选及限制。`candidate_unverified` 不是成功抓取；候选 `score` 是现有几何质量指标，不是抓取成功率。结果不可用作绝对位置精度真值。

## 本地数据的首轮诊断

- `raw_036` 使用上述示例框时得到一个 `candidate_unverified`；叠加图显示两个上下叠放箱子的正面合并到同一深度簇。支持平面可能选到背景，看到的主要是正面而非顶面，即使分数较高也不能当吸附点。框坐标来自离线目视诊断，不是人工真值或正式标注。
- `raw_037` 空场用框 `[300,150,500,350]` 返回 `ambiguous`，原因是所关联的大簇多数在框外。这是一次负例诊断，不是空场误检率。
- 空场和上述旧箱子图都没有独立的抓取点真值；需要顶面、支撑面同时可见的数据，以及人工确认/独立参考，才能评估实际定位与抓取效果。
