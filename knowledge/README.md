# `knowledge/`：知识资产（只放数据与文档，不放可执行代码）

按迁移计划书 D1 / 4.6：知识资产要传给下一届，跟着"运行时代码"走会被频繁重排打散。

| 子目录 | 放什么 | 说明 |
|---|---|---|
| `docs/` | 教程、进度、规范、契约以外的说明、`archive/` 历史文档 | 见 `docs/README.md` 索引 |
| `calibration/` | 可 1:1 打印的棋盘（PNG + PDF） | 打印选「实际大小」，别用「适合页面」 |
| `models/` | YOLO 的 ONNX 权重与类名表（**不进版本库**） | 用 `python lab/export_yolo.py` 自己导出 |
| `images/` | README 用到的截图 | 体积小，可以进库 |

**大文件规则**：单个文件超过 10 MB 一律不进版本库，走网盘或 release 附件；
仓库里只留"怎么获取"的说明。权重、数据集、视频都适用。

图像上渲染中文要额外字体，但当前版本不需要：`cv2.putText` 用的是 Hershey 矢量字体，
不含汉字字形，传中文会画出问号且不报错——所以图上标签一律 ASCII，中文只进日志。
