## 一、当前阶段

**2D 链路全部落地（判色 / ArUco / 位姿 / 标定 / YOLO），并完成真机验收；深度相机那条线由队友接入。**

- **结构**：`vision/`（运行时代码，30 个 .py）+ `lab/`（一次性工具）+ `knowledge/`（文档与素材）三层；
  主入口 `python -m vision` 只有 **6 条**（run / live / doctor / demo / hsv-tuner / clean）。
- **回归**：`pytest tests/ -q` → **121 项**（判色 / 几何 / 配置 / ArUco / 标定 / 位姿 / YOLO /
  api / 架构约束 / 入口冒烟 / 合成数据集），容器与宿主 venv 都通过。
- **端到端**：合成图 3 帧 × 6 块 = 18 个色块，实得 18、判色 18/18（命中率 1.0）；
  ArUco 图组 9/9，中心 0.00 px、四角 ≤0.23 px。
- **位姿**：合成七组扫描通过；**真机已验收**（2026-10-25）——位移差分误差 ≤0.2%（200/400 mm），
  倾角 30°/50°/60° 误差 −1.0 / −0.5 / +1.2°；绝对距离比卷尺大 ≈12 mm（镜头前端面 ≠ 光心的基准差）。
- **YOLO**：ONNX + `cv2.dnn` 接入；v2 同分布指标 P 0.971 / R 0.939 / mAP@0.5 0.970，
  但已确认 test 有相邻帧跨 train（max 0.971），**不能当泛化指标**。
  v3 整组留出重训后（train 181 图、test g3tilt+g4stack 52 图/173 框）：
  基线 P 0.813 / R 0.824 / mAP@0.5 0.850；加 **90° 旋转增广（v3_aug2）** 后
  **P 0.912 / R 0.806 / mAP@0.5 0.885**，类别错 18→6、g3tilt R 0.681→0.815，当前采用；
  180° 版本（v3_aug）FP 暴涨，已弃用。剩余问题：FP 3→13、合并 15 基本没动；
  下一步补空背景/边缘/叠放样本。颜色仍由 HSV 判，距离不归 2D。
  详见 `knowledge/docs/YOLO训练与评测记录.md`。
- **深度相机**：算法在 `vision/depth/`、ROS 2 外壳在 `ros2_ws/src/vision_depth/`（队友维护），合成数据位置误差 3.86 mm。
- **还没做**：补拍难样本（空背景/海报、贴边截断、远景、单色 top、叠放、**手持/运动**；
  清单见 `YOLO训练与评测记录.md` 5.1）、场地 HSV 阈值重调（等场地）、多码融合/场地坐标。
  2026-11-01 现场：放地上基本正常，**拿在手里类别/边界不稳**（训练集几乎全是地面静态）。

1. **YOLO2D 收尾**：`feat/训练数据增强` 已推到远端（9e0d514），把本地审计提交推上去并**发 PR**（目前无 open PR）；
   PR 描述里注明"0.96 是同分布指标、去重后约 0.90"；
2. **✅ v3 基线已训完**：train g1+g2+g6（181/789）、val g5（15/52）、test g3+g4（52/173）；
   诚实指标 **P 0.813 / R 0.824 / mAP@0.5 0.850**（同分布 mix4 的 0.970 不能当泛化）。
   主要错误：g3tilt 类别错 10（R 0.681）、g4stack 合并 8；下一步按训练记录第 5 节补旋转/叠放样本；

   6 个 FP 多为边缘碎片与环境；v2 test 只有 36 张（g6far 占 123/168 框），v3 test 也只有 52 张/173 框；

   640 留着做离线复核；

6. **统一倾角载体**（位姿侧）：30°/50° 之前用弯曲 A4 纸测的，用手机屏幕重测一遍；
7. **等场地**：HSV 阈值重调（规则 V2 的配色已验证落在现有阈值内，见 README 坑 5）；
8. **距离/坐标**：2D 不估距离，交给深度相机；多码融合等主逻辑定原点。

## 七、明确不做（及原因）

| 任务 | 状态 / 原因 |
|---|---|
| 2D 侧 ROS 2 节点 | **不做**：`vision/` 保持纯 Python 库 + CLI，不 import rclpy；深度侧的外壳在 `ros2_ws/` |
| YOLO 真图训练 | ✅ 已完成（mix4，248 真图为主 + 合成）；后续只补难样本，不再等物块 |

| 场地光照/阈值标定 | **等场地**：规则配色的 HSV 已被现有阈值覆盖，现场只需按曝光复核 |
| 多码融合 / 场地坐标 | **等主逻辑**：要先定"场地坐标系原点"，否则算法做了也没法用 |
